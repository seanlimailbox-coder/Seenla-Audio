## Highlights

- Clipper, Compressor, and Gate share a frozen-history inspector that moves with the cursor and keeps readouts centered. Clipper uses a single-row badge; Compressor and Gate retain their additional detector readings. Gate preserves Shift-drag noise selection.
- Recent dynamics display refinements include smoother page and bypass transitions, threshold badge placement, and gain-reduction metering.
- Limiter includes smoother menus with readable preset rows and a ceiling range down to −18 dB.

## Installation

Download **`Open-Dynamics-Beta-1-macOS-universal-2026-10-18.pkg`**. On Installation Type, select any plugins and choose **AU**, **VST3**, or **both** independently for each one. All formats are initially selected.

- **macOS 11 or later**, universal `arm64` + `x86_64`.
- Installs for the **current account** to `~/Library/Audio/Plug-Ins/Components/` (AU) and `~/Library/Audio/Plug-Ins/VST3/` (VST3).
- Selected formats replace their existing copies in those user folders. Unselected formats stay in place. Presets and session files are preserved.
- Quit audio applications before installation; reopen and rescan afterwards if necessary.
- This package contains the latest listed versions only, with no CLAP builds.

[Full installation instructions](https://github.com/seanlimailbox-coder/Seenla-Audio/blob/main/docs/installation.md)

## Beta limitations and validation

The installer is **unsigned and not notarized by Apple**. Plugin bundles use **ad-hoc signatures**. macOS may block downloaded software; include the exact message in any support report. These builds are beta software and have not been tested in every host or workflow. Keep copies of your existing plugins and important sessions before updating.

All eight source AU/VST3 bundles passed their format validators on both architectures. Installer payload signatures, architectures, beta metadata, extracted file hashes, and all 256 format-selection combinations were checked. Executable code matches the validated source builds; beta packaging changes version metadata. The package selection tests previewed installation without installing it.

Plugin names and IDs are preserved for session recall. Check a copy of an important session before relying on the beta in ongoing work.
