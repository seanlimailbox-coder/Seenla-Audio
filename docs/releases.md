## Versioning

Each plugin retains its own numeric version. **Beta 1** identifies this collection snapshot; the date identifies when it was published. Bundle build metadata records the beta suffix, such as `2.4.23b1`, while numeric host version values remain compatible.

This prerelease uses the tag **`beta-1-2026-10-18`**. Future releases should clearly state their beta/stable channel, date, included plugin versions, formats, architectures, minimum macOS version, and signing status.

## Downloads

Packages belong in GitHub Releases rather than in the documentation branch. Keep version manifests and SHA-256 checksums alongside the installer. Retain previous releases so users can return to an identifiable version.

Source code is not included in this documentation repository.
