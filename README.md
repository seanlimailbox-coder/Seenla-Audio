# Seenla Audio

Four audio plugins for shaping transients, controlling dynamics, reducing noise, and managing output levels.

## Open Dynamics — Beta 1

**October 18, 2026 · [Download for macOS](https://github.com/seanlimailbox-coder/Seenla-Audio/releases/tag/beta-1-2026-10-18)**

| Plugin | Use it to |
| --- | --- |
| [Open Clipper](docs/plugins.md#open-clipper) | Shape transients, add density, and control peaks. |
| [Open Compressor](docs/plugins.md#open-compressor) | Control dynamic range and shape the movement of a sound. |
| [Open Gate](docs/plugins.md#open-gate) | Reduce noise and spill, or shorten sustain between events. |
| [Open Limiter](docs/plugins.md#open-limiter) | Set final output levels and monitor peaks and loudness. |

## Requirements

- **macOS 11 or later**, on Apple Silicon or Intel.
- An audio application that supports **Audio Units (AU)** or **VST3** effects.

## Installation

Download the `.pkg` from the [Beta 1 release](https://github.com/seanlimailbox-coder/Seenla-Audio/releases/tag/beta-1-2026-10-18). The installer lets you choose which plugins to install and select AU, VST3, or both for each one.

The installer is unsigned and not notarized by Apple, so macOS may block installation. See the [installation guide](docs/installation.md) for requirements, plugin folders, and troubleshooting.
